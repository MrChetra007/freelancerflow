
FREELANCEFLOW - Client Management App
======================================

WHAT IT DOES
------------
FreelanceFlow is a mobile app for freelancers to manage their clients, projects, payments, invoices, expenses, and time tracking in one place. It helps track project progress, log payments, generate invoices, monitor business performance, track billable hours and expenses, and automate recurring billing.

AUTHENTICATION
---------------
- Email/Password sign up and login
- Google OAuth sign in
- Auto-redirect to dashboard on successful auth
- Profile created automatically via Supabase trigger on signup

ONBOARDING & FIRST-RUN
-----------------------
- Landing screen: 4-slide app intro shown before login (Welcome, Clients & Projects, Time & Expenses, Stay Organized)
- Profile setup walkthrough after first signup: Full Name → Business Info (name, email, phone, address) → Preferences (hourly rate, currency, timezone)
- Setup can be skipped and completed later from Profile screen
- is_onboarding flag in profiles table tracks completion status

MAIN SCREENS
------------
1. Dashboard (v2)
   - 7 stat cards: This Month, Expenses, Net Profit, Unpaid, Overdue, Active Projects, Unbilled Time
   - Active Timer Banner: live-running timer with project name, elapsed time, and stop button
   - Revenue & Expenses dual bar chart (last 6 months, tap for tooltip with profit)
   - Recent activity feed with event types: payment, invoice, project, client, time, expense, recurring
   - Quick Actions: Expenses, Time Tracking, Recurring

2. Clients
   - List all clients with search, tag filter (horizontal chip row)
   - Sort by: Name / Recent / Most Revenue
   - Add/Edit client (name, email, phone, company, country, currency, default hourly rate, tags, notes)
   - Archive clients
   - Client Detail Screen (4 tabs):
     a. Overview: client info, projects/time/expenses summary cards, total earned
     b. Projects: list of client projects with status, tap to view project detail
     c. Time: total hours and value summary + time entry list
     d. Expenses: total expenses summary + expense list
   - Context-aware FAB that changes per tab (Edit / New Project / Log Time / Add Expense)

3. Projects
   - List projects with search and status filter
   - Add/Edit project (title, description, budget, status, dates, currency)
   - Milestone tracking within projects
   - Status: In Progress, Completed, On Hold, Cancelled
   - Project Detail Screen (3 tabs):
     a. Details: project info card + milestones section
     b. Time: total hours/value summary (precise duration, not rounded) + time entry list + Add Entry / Start Timer buttons
        - Start Timer: checks for active timer, fetches hourly rate from profile, starts live timer
        - Total Hours: computed from full duration seconds (not rounded to whole hours)
     c. Expenses: total expenses summary + expense list + Add Expense button (auto-fills project + client)
        - Pro gate: non-premium users see amber lock button with upgrade prompt
   - Expandable header: status badge → budget + deadline → project title → description (collapsed shows status badge + title)

4. Payments
   - Track payments per client/project
   - Add/Edit payment (amount, status, method, due date, paid date)
   - Payment methods: Bank Transfer, PayPal, Wise, Crypto, Cash, Stripe, Other
   - Status: Paid, Unpaid, Partial, Overdue, Refunded
   - Monthly total at top, grouped by month

5. Invoices (v2)
   - Create invoices with line items
   - Add tax and discount
   - Generate and share PDF (WhatsApp, Gmail, Drive, etc.)
   - Upload PDF to Supabase Storage
   - Status: Draft, Sent, Paid, Overdue, Cancelled
   - Import Time Entries: bottom sheet to select unbilled time entries, adds as line items (qty = hours, unit_price = hourly_rate)
   - Import Expenses: bottom sheet to select billable unbilled expenses, adds as line items (qty = 1, unit_price = amount)
   - After import: marks entries as billed and links to invoice
   - "Make this recurring" toggle: when enabled, creates a recurring invoice template alongside the draft invoice
     - Frequency picker: Weekly, Bi-weekly, Monthly, Quarterly, Yearly
     - First issue date picker
     - Due in X days field
   - Edit existing invoices with line item management
   - Pro feature (non-premium users see upgrade prompt)

6. Expenses (v2) — Pro feature
   - List expenses with category filter and search
   - Add/Edit expense (amount, category, description, date, project/client link, billable flag, notes)
   - Receipt upload via image picker (stored in Supabase Storage)
   - Categories: Software, Hardware, Travel, Accommodation, Meals, Marketing, Freelancer, Office, Other
   - Each category has a unique color and icon
   - Billable/unbilled tracking, swipe to delete with undo
   - Expense breakdown pie chart by category
   - Monthly total at top
   - Pro gate on Add Expense buttons throughout the app

7. Time Tracking (v2)
   - Active timer card at top: shows project name, live HH:MM:SS clock, stop button
   - Green pulsing dot indicator when timer running
   - Monthly summary bar: Total Hours, Billable amount, Unbilled amount
   - Filter chips: All / Billable / Unbilled / This Week / This Month
   - Entries grouped by date (Today, Yesterday, day-of-week, or full date)
   - Each entry shows: project name, description, duration, billable amount, billed/unbilled badge
   - FAB with bottom sheet: Start Timer or Log Manual Entry
   - Manual entry form: project, description, hourly rate (auto-fetched from client profile, then user profile), start date/time, end date/time, billable toggle
   - Edit existing entries, delete with confirmation dialog
   - Only one timer can run at a time per user
   - Global floating timer overlay (top center, 50% width, pulsing green dot, tappable to time tracking screen, persistent across all routes)

8. Recurring Invoices (v2)
   - Create recurring invoice templates from invoice create screen or dedicated screen
   - Fields: client, project (optional), line items, frequency, first issue date, due days, tax, discount, currency, notes, payment terms
   - Frequency: Weekly, Bi-weekly, Monthly, Quarterly, Yearly
   - List of active templates with frequency badge, next issue date, line item count
   - Toggle active/inactive
   - Auto-generation on app launch: checks for due templates, creates draft invoices, advances schedule
   - Shows notification when invoice is auto-created

9. Settings (v2)
   - Profile management (name, business info, avatar upload, hourly rate, currency, timezone, tax ID, payment terms)
   - Avatar upload via image picker → Supabase Storage avatars bucket → profile_url saved to profiles table
   - Full name read from profiles table (not auth metadata)
   - Timer rounding: None / 5 min / 15 min / 30 min
   - Theme (Light / Dark / System)
   - Notification preferences: Payment Reminders, Project Reminders, Invoice Reminders
   - Notification tester: send immediate, schedule in 10s / 1min, view/cancel scheduled notifications (free feature)
   - Premium subscription management
   - Privacy Policy and Terms of Service

10. Premium Subscription (In-App Purchase)
    - Upgrade to Pro via Google Play Billing (in_app_purchase package)
    - Restore purchases with Completer pattern (awaits stream delivery, 15s timeout)
    - Premium status stored in SharedPreferences (no server-side validation)
    - Cancel subscription opens Google Play Store subscriptions page
    - Pro features: Expenses (CRUD), Invoices (create/PDF), Receipt upload, Unbilled time filters, Expense pie chart

NOTIFICATIONS
--------------
- Local notifications via flutter_local_notifications
- Payment overdue: daily at 9am if overdue
- Project deadline: 24h before deadline
- Milestone due: on due date at 9am
- Invoice unpaid: every 7 days after due date
- Recurring generated: immediately when auto-created
- Weekly summary: every Monday at 8am
- In-app notification bell with unread badge
- Tap notification navigates to relevant screen (debugPrint only — navigation not yet wired)
- Stable notification IDs to avoid duplicates
- Notification types: payment_overdue, project_deadline, milestone_due, invoice_unpaid, recurring_generated, weekly_summary
- Test and schedule notifications from Settings (no premium gate)

DATA FLOW
---------
1. User opens app → Landing screen (intro slides) → Sign Up / Log In
2. First signup → Profile setup walkthrough (name, business, preferences)
3. Add a Client first (optionally add tags and default hourly rate)
4. Create a Project linked to a Client
5. Add Milestones to track project progress
6. Start Timer or log Time Entries for the project/client
7. Add Expenses linked to client or project (with optional receipt photo) — Pro feature
8. Log Payments for the project
9. Create Invoice with line items (can import unbilled time entries and expenses) — Pro feature
10. Optionally make invoice recurring for automated future billing
11. Dashboard shows summary, net profit, and business overview
12. Recurring invoices auto-generate on app launch

TECH STACK
----------
- Flutter (Android)
- Supabase (Backend - Auth, PostgreSQL Database, Storage)
- Riverpod (State Management with code generation)
- GoRouter (Navigation with ShellRoute for bottom nav)
- Freezed (Immutable models)
- fl_chart (Charts: bar, pie, dual-axis)
- PDF generation for invoices
- image_picker for receipt uploads and avatar uploads
- flutter_local_notifications for reminders
- in_app_purchase for Pro subscription
- Supabase RPC functions for recurring invoice auto-generation and milestone checks

SECURITY
--------
- Supabase Auth with JWT
- Row-level security (RLS) on all tables
- User can only access their own data
- Private storage bucket for invoices and receipts; avatars bucket for profile images
